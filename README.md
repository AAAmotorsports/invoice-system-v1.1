# 請求書発行システム（デモ版）

小規模ショップ向けの請求書・在庫・経費管理システムのデモ版です。

## 🌐 デモを試す

**公開URL**: https://aaamotorsports.github.io/invoice-system-v1.1/

## ✨ 主な機能

- 📄 **請求書作成** — 顧客・商品を選ぶだけでPDF生成（日本語対応）
- 📦 **在庫管理** — カテゴリ分類、数量管理、CSVインポート
- 🤖 **納品書AI取込** — 納品書の写真・PDFから商品を自動抽出（Anthropic APIキー要）
- 🧾 **経費請求（立替明細書）** — 領収書添付付きの立替請求書
- 📋 **合計請求書** — 複数請求書と入金をまとめた合計請求書
- 📊 **ダッシュボード** — 月別/顧客別売上、粗利、期間指定
- ⚠️ **未請求アラート** — 入庫したのに請求してない商品を通知

## 🎯 デモ版について

- **完全に架空のサンプルデータ**が入っています（実在の会社・顧客ではありません）
- データはブラウザ内（LocalStorage）のみに保存
- クラウド同期なし（別端末では別データ）
- 全機能を無料で試せます

## 🚀 使い方

1. 上記URLにアクセス
2. 初回起動時に「**サンプルデータで開始**」をクリック
3. ダッシュボード・請求書作成・在庫管理などを自由に操作
4. データを削除したい場合は「バックアップ」タブで確認、またはブラウザのデータ削除

## 💡 AI 機能を使うには

領収書・納品書の自動読み取りには **Anthropic API キー** が必要です：

1. https://console.anthropic.com/settings/keys でキー取得
2. 設定タブ → AI機能セクションで貼り付け
3. 領収書に「🤖 AIで抽出」ボタン、在庫に「🤖 納品書から取込」ボタンが使えます

利用料金: 約1〜15円/枚（従量課金）

## 📱 スマホ / PWA インストール

- iPhone: Safari で開いて「共有 → ホーム画面に追加」
- Android: Chrome で開いて「ホーム画面に追加」
- PC (Chrome/Edge): アドレスバー右の「インストール」

## ⚙️ このシステムを自社で使いたい

現在デモ版はデータ同期なし（1端末のみ）です。
複数端末で共有したい場合は Firebase 設定が必要です。ご相談ください。
