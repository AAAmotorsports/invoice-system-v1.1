完全自動化された請求書・在庫管理システム - Ver 1.1

## 🆕 最新アップデート (Ver 1.1)

- ✅ **顧客名プルダウン機能**：過去の顧客を選択可能、入力ミス防止
- ✅ **Freee会計ソフト連携**：売上データをCSVで一括エクスポート

## 🌟 主な機能

### 📸 納品書AI読み取り
- 納品書の写真をアップロード
- AIが自動で商品名・数量・単価を抽出
- ワンクリックで在庫に追加

### 📄 請求書自動生成
- 顧客名をプルダウンから選択（または新規入力）
- 在庫から商品を選択
- PDFを自動生成（日本語対応、文字化けなし）
- ダウンロードして即使用可能

### 📊 購入履歴管理
- 顧客別の購入履歴
- 過去の請求書を検索・閲覧
- いつでもPDF再生成
- **NEW!** Freee形式でCSVエクスポート

### 🌐 クラウドベース
- どこからでもアクセス可能
- PC・Mac・iPhone・iPad対応
- データは自動保存・同期
